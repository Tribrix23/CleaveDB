CleaveDB is a hybrid document, relational, and graph database that brings documents, relationships, and semantic search together in one system. Its Rust storage engine and English-like query language, **CleaveQL**, let you store data, explore connections, and search by meaning.

- **Document storage:** Organize JSON documents in buckets.
- **Native graph bonds:** Connect documents and traverse relationships across buckets.
- **Semantic search:** Find relevant data by meaning using Transformer embeddings.
- **One query language:** Use CleaveQL to read, write, filter, aggregate, and explore connected data.

Visit the [CleaveDB website](https://cleavedb.devctr.com/) for documentation and getting started.
